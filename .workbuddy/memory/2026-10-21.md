## DOCX 与 HTML 排版对齐（22:4x）
- 问题：docx 与 html 看起来两套格式。原因有二：① 生成器字体用微软雅黑、行距 1.5、字号 12pt、无段距、无副题行，与 html 的 CSS（serif / 1.95 / 18px / .55em / 书名·主角）不一致；② 磁盘上的 docx 曾被本地文档编辑器二次保存，标题段落的 style 被剥离，变成带两个空格的普通段落（加粗居中全丢）。
- 修复：`panda_build.py` 的 `make_docx` 重写为 CSS 逐项映射，且全部格式**内联**在每段（pPr/rPr），不依赖样式表，避免被编辑器再保存时丢失：
  宋体+Times New Roman / 正文 13.5pt(27) / 行距 468 auto(1.95) / 段后 149(0.55em) / 首行缩进 2 字符 / 标题 21pt(42) 加粗居中字距17 / 副题 11pt 灰 #9A9A94 居中 / 页边距 上下2.5cm 左右2cm。
- 验证：134 段，标题居中加粗，副题行存在，全文 0 处微软雅黑。本机无 LibreOffice，无法渲染成图核对，只能校验 XML。
