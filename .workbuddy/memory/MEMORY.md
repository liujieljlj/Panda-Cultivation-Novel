# 项目长期约定

## 《熊猫成仙，从青竹山开始》（用户自写小说，改编自 朝北海《玄蛇成仙，从镇族老祖开始》）

### 核心设定
- 主角：**陆明远**，上一世是蓝星熊猫饲养员，这一世穿越为异世界熊猫。
- 种族：**青竹食铁兽**（熊猫古称；不要用貔貅等其他瑞兽名）。
- 地点：**青竹山**、**竹影潭**、**老竹王**（巨竹）。
- 面板（**自创图鉴卡，不可退回原著字段**）：首行 `【竹海图鉴 · 卷一】`，字段为单字标签 录／食／咬／气／寿／赋／术／限／鉴。具体值：录 陆明远，青竹食铁兽；食 笋为先，竹叶次之；咬 三阶，可断青竹；气 练气中期，卡了十二年没动；寿 五十 / 三百；赋 **驭竹**；术 **断竹、竹刺**；限 凡兽之身，止于练气巅峰；鉴 未启。
- **禁用旧名**：控木、木元弹、凝木为箭、血脉、境界、寿命、镇族系统、天赋（作字段名）一律不得再出现。能力体系固定为 驭竹 / 断竹 / 竹刺。
- 金手指：**竹海图鉴**，不是原著的「镇族系统」。激活条件是「要一族才应」，而他孤身一头算不得族，故需下山成族。**不要再出现「镇族系统」「血脉：普通妖兽」等原著字段**。
- 修为天花板源自面板「上限：凡兽，止于练气巅峰」。
- 金手指机制：**竹海图鉴**感应到「可录之族」时提示立族；**一人即可立族**（面板不写人数）。立族后得**族运**点（与家族成员境界挂钩），可加点 血脉／寿元／天赋／神通／境界；家族越大族运越多。
- 已有角色：**竹长庚**，竹家家主，青溪镇（已录为第一族）；毒蛇**石蝰**（西边旱沟，练气后期，鳞甲硬如铁）。陆明远任竹家**供奉灵兽**。
- 陆明远的祛毒手段：**驭竹吸毒**（掰断青竹、竹芯出白须入血脉找毒，竹节由下往上变黑，黑透后整竹塌掉）。不要再用"灵气包裹、神魂分离毒素"的写法。
- 已获神通：**大小如意**（身随意动，极小如狸，极大如牛，比原身高一头）。第一章末：境界 练气后期、天赋 驭竹·二阶（十丈内竹随心动）。

### 写作约定（用户明确要求，必须遵守）
1. **禁止使用破折号「——」**。也不要用省略号「……」凑节奏，用逗号或直接断句。
2. **篇幅贴近原著对应章节**，偏差放宽到 **±10%** 即可（2026-10-21 用户调整，不再按 ±5% 死卡）。原著第 1 章正文 3040 字。
3. 保留原著节奏：短句、短段、内心独白推进，几乎无对话。
4. 用户指定改写点要落实到位（第 1 章：吃鸡改为找竹笋、增加熊猫可爱画面）。
5. **不得照抄原著句子**：章节开头第一句、地点交代句、系统面板、通用短语都要重写。用 `python check_similarity.py 原章.txt 新章.txt` 自检，门槛：整体相似度 ≤20%、最长连续相同片段 ≤15 字、15 字连续重合率 ≤0.5%、8 字以上长句完全重复 0 句。
